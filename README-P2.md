# P2 – A Slow Sensor in the Loop

**Owner:** Israa Alyazouri

This module shows how a slow sensor affects a PID feedback loop. Users can adjust the sensor time constant and PID gains, then compare the actual output and the sensor reading on the same plot. The page also displays the loop status and overshoot and includes a “Predict, then check” activity.

**Validation:** I tested the fast and slow sensor cases, sustained oscillation, and instability. The proportional-only (P-only) check passed with a final output of **0.900** and a steady-state error of **10.0%**.
