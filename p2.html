Simulation equations

For the plant, dy/dt = (Ku − y)/τ. For the sensor, dyₛ/dt = (y − yₛ)/τₛ. The PID uses e = r − yₛ, so u = Kₚe + Kᵢ∫e dt − Kd dyₛ/dt during the constant step. RK4 integrates the plant, sensor and integral states together.

Validation

P-only unit step: K = 1, plant time constant = 1 s, sensor time constant = 0.05 s, Kp = 9, Ki = Kd = 0. Expected final output = 0.900 and steady-state error = 10.0%.
