02

Plant and its source

First-order speed model used for the exercise

OPEN-LOOP TRANSFER FUNCTION
G(s) = K / (τs + 1)

Input: PWM duty fraction 0–1. Output: shaft speed (RPM).

K ≈ 500 RPM / unit PWM — assumed ideal linear scaling from the selected 500 RPM listing at rated 6 V, without load; not a measured motor gain.

τ = 0.25 s — illustrative assumption. Actual τ cannot be read from the 500 RPM rating and must be found from a PWM step test.

Identification later: log PWM and encoder RPM; estimate K = Δsteady RPM / ΔPWM and τ at 63.2% of the step response.

06

Design equations

PI controller applied to a first-order plant

WITHOUT SATURATION / SAMPLING
τs² + (1 + KKp)s + KKi = 0

Choose ζ = 0.7 (inside the recommended 0.6–0.8 range). For PI (Kd = 0), select a natural frequency ωn and compute:

Kp = (2ζωnτ − 1) / K
Ki = (τωn²) / K

This is an illustrative continuous-time pole design; real PWM limits, encoder quantization, and digital sampling can alter the response.

Generated ESP32 / DRV8833 Arduino sketch

One forward-direction motor speed loop with encoder feedback; values update as the controls change

Before uploading to hardware: set the actual encoder counts per output shaft revolution, verify ESP32-safe encoder voltage, motor driver supply / nSLEEP, and chosen GPIO wiring. The sketch intentionally keeps the motor off until a valid count is configured. Designed for Arduino-ESP32 3.x LEDC API.
